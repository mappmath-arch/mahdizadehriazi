پایه تحصیلی: نهم متوسطه نام دبیر: حسین مهدی‌زاده بارم کل: ۲۰ نمره (هر سؤال ۲/۵ نمره)
ردیف شرح سؤالات و پاسخ‌نامه تشریحی بارم
۱ مشخص کنید کدام‌یک از عبارت‌های زیر یک مجموعه را مشخص می‌کند؟ در صورت مجموعه بودن، آن را با آکولاد نوشته و تعداد اعضا را تعیین کنید:
الف) شمارنده‌های اول و دورقمی عدد ۶۰   |   ب) سه عدد طبیعی فرد متوالی   |   ج) عددهای صحیح منفیِ بزرگ‌تر از ۴-
مشاهده پاسخ تشریحی سؤال ۱
الف) شمارنده‌های اول عدد ۶۰ عبارتند از ۲، ۳ و ۵. هیچ‌کدام دورقمی نیستند؛ بنابراین این مجموعه تهی (∅) است (تعداد اعضا = ۰).
ب) عبارت «سه عدد طبیعی فرد متوالی» مشخص و معین نیست؛ بنابراین مجموعه را مشخص نمی‌کند.
ج) عددهای صحیح منفی بزرگ‌تر از ۴- کاملاً مشخص هستند: {۱- ، ۲- ، ۳-} (تعداد اعضا = ۳).
۲/۵
۲ مجموعه A = { ۳, {۳}, ۵, ۳, {۳, ۵} } مفروض است:
الف) تعداد اعضای متمایز مجموعه A چندتاست؟
ب) درستی یا نادرستی هر عبارت را مشخص کنید:   ۱) {۳} ∈ A     ۲) ۵ ∉ A     ۳) {۳, ۵} ∈ A     ۴) ∅ ∈ A
مشاهده پاسخ تشریحی سؤال ۲
الف) با حذف عضو تکراری (۳ دوم)، اعضای متمایز عبارتند از: ۳، {۳}، ۵ و {۳, ۵}. بنابراین تعداد اعضا برابر ۴ است.
ب - ۱) درست. مجموعه {۳} مستقیماً به عنوان یک عضو در A قرار دارد.
ب - ۲) نادرست. عدد ۵ عضوی از مجموعه A است (∈).
ب - ۳) درست. مجموعه {۳, ۵} عیناً به عنوان یک عضو داخل A است.
ب - ۴) نادرست. تهی (∅) عضوی از مجموعه A نیست.
۲/۵
۳ مقادیر مجهول x و y را چنان بیابید که دو مجموعه A = { ۲x - ۱, ۱۶, √۴۹ } و B = { ۷, ۲y, ۱۱ } با یکدیگر برابر باشند.
مشاهده پاسخ تشریحی سؤال ۳
ابتدا ساده می‌کنیم: √۴۹ = ۷. پس A = { ۲x - ۱, ۱۶, ۷ } و B = { ۷, ۲y, ۱۱ }.
با توجه به تساوی دو مجموعه، عدد ۱۶ از مجموعه A باید با ۲y برابر باشد:
۲y = ۱۶  ⇒  ۲y = ۲۴  ⇒  y = ۴
همچنین عضو ۲x - ۱ باید برابر با ۱۱ باشد:
۲x - ۱ = ۱۱  ⇒  ۲x = ۱۲  ⇒  x = ۶
۲/۵
۴ مجموعه M شامل اعداد حسابی که مجذور آن‌ها کمتر از ۸ است را در نظر بگیرید:
الف) تمام زیرمجموعه‌های دو عضوی آن را بنویسید.
ب) اگر ۳ عضو جدید به این مجموعه اضافه شود، تعداد کل زیرمجموعه‌های آن چند برابر می‌شود؟
مشاهده پاسخ تشریحی سؤال ۴
اعداد حسابی که توان دوم آن‌ها کمتر از ۸ است عبارتند از: ۰، ۱ و ۲. پس M = {۰, ۱, ۲} (تعداد اعضا n = ۳).
الف) زیرمجموعه‌های ۲ عضوی: { {۰, ۱} ، {۰, ۲} ، {۱, ۲} }
ب) تعداد کل زیرمجموعه‌ها در ابتدا ۲۳ = ۸ بوده است. با اضافه شدن ۳ عضو، تعداد اعضا ۶ شده و زیرمجموعه‌ها ۲۶ = ۶۴ می‌گردد. نسبت تغییر: ۶۴ ÷ ۸ = ۸ برابر.
۲/۵
۵ اگر A = { ۱, ۲, ۳, ۴, ۵ } و B = { ۵- , ۱- , ۳ , ۵ } باشند، مجموعه‌های زیر را با نوشتن اعضا مشخص کنید:
الف) A ∩ B          ب) B - A          ج) (A ∪ B) - (A ∩ B)
مشاهده پاسخ تشریحی سؤال ۵
الف) اشتراک (A ∩ B): اعضای مشترک: { ۱, ۳, ۵ }
ب) تفاضل (B - A): اعضایی که در B هستند ولی در A نیستند: { ۵- , ۱- }
ج) تفاضل متقارن: اعضایی که فقط در یکی از دو مجموعه حضور دارند: { ۵- , ۱- , ۲ , ۴ }
۲/۵
۶ در یک کلاس ۳۲ نفره، ۱۹ نفر در تیم فوتبال و ۱۵ نفر در تیم والیبال عضو هستند. اگر ۷ نفر در هر دو تیم حضور داشته باشند:
الف) چند نفر فقط در تیم فوتبال عضو هستند؟   |   ب) چند نفر در هیچ‌یک از این دو تیم عضو نیستند؟
مشاهده پاسخ تشریحی سؤال ۶
تعداد مشترک دو تیم = ۷ نفر.
الف) فقط فوتبال: ۱۹ منهای ۷ = ۱۲ نفر.
ب) خارج از هر دو تیم: کل اعضای حاضر در تیم‌ها برابر است با ۱۲ + ۷ + ۸ = ۲۷ نفر. پس ۳۲ منهای ۲۷ = ۵ نفر در هیچ تیمی عضو نیستند.
۲/۵
۷ در خانواده‌ای با ۳ فرزند، احتمال هر یک از پیشامدهای زیر را بیابید:
الف) خانواده حداقل ۲ فرزند پسر داشته باشد.   |   ب) فرزند اول و سوم هم‌جنس باشند.
مشاهده پاسخ تشریحی سؤال ۷
تعداد کل حالت‌های ممکن برابر ۲۳ = ۸ حالت است.
الف) حداقل ۲ پسر: حالت‌های (پ،پ،پ)، (پ،پ،د)، (پ،د،پ) و (د،پ،پ) که ۴ حالت است. احتمال: ۴/۸ = ۱/۲.
ب) اول و سوم هم‌جنس: ۴ حالت رخ می‌دهد. احتمال: ۴/۸ = ۱/۲.
۲/۵
۸ از بین کارت‌های شماره‌گذاری‌شده از ۱ تا ۲۰، یک کارت به تصادف بیرون می‌کشیم. احتمال پیشامدهای زیر را محاسبه کنید:
الف) عدد کارت اول و دورقمی باشد.   |   ب) عدد کارت مضرب ۳ یا مضرب ۵ باشد.
مشاهده پاسخ تشریحی سؤال ۸
الف) اعداد اول دورقمی بین ۱ تا ۲۰ شامل ۱۱، ۱۳، ۱۷ و ۱۹ است (۴ حالت). احتمال: ۴/۲۰ = ۱/۵.
ب) کارت‌های مضرب ۳ یا ۵ پس از حذف مضرب مشترک (۱۵)، در مجموع ۹ کارت هستند. احتمال: ۹/۲۰.
